01. Executive Overview

Modern cloud environments frequently suffer from the Over-Privilege Gap—the discrepancy between assigned structural administrative rights and actual daily operational needs. To minimize developer friction, roles are often provisioned with wildcards (e.g., "Action": "*").

AHAR solves this challenge through deterministic set theory and time-window filtering. Rather than relying on unpredictable machine learning models, AHAR analyzes CloudTrail logs, prunes background noise, and mathematically enforces the Principle of Least Privilege (PoLP) without breaking critical administrative workflows.

02. Architecture & Pipeline

The AHAR engine processes telemetry through a clean 4-phase unidirectional architecture:

1. Telemetry Ingestion: Asynchronously ingests raw CloudTrail CSV flat files and normalizes events into standardized Service:Action strings.

2. Temporal & Diurnal Slicing: Removes weekend logs and restricts active parsing to business hours (9:00 AM – 6:00 PM) to isolate real human activity from automated machine cron jobs.

3. Set-Theoretic Union: Calculates the union $E \cup B$ between observed empirical actions ($E$) and an immutable Mandatory Security Baseline ($B$) to completely solve the cold-start problem.

4. Clean-Slate JSON Compilation: Compiles fresh, compliant AWS IAM JSON manifest files from scratch using an implicit-deny strategy.
